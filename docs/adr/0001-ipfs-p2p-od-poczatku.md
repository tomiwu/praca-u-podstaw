# Kod i dane w IPFS (P2P) od początku

Rozważano centralną instancję Forgejo z P2P jako dodatkiem. Zdecydowano, że projekty są udostępniane w IPFS od pierwszej wersji, a centralnie działa tylko system zadań. Konsekwencja: IPFS nie usuwa danych na żądanie, więc nie trafiają tam dane osobowe (RODO), a prywatne pliki są szyfrowane przed publikacją.
